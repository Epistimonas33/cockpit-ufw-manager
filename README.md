# Cockpit UFW Manager

A lightweight Cockpit plugin to manage UFW (Uncomplicated Firewall) rules.

## Features
- Enable/Disable UFW firewall
- View and delete active firewall rules
- Add new port rules easily
- Auto-starts services upon installation

## Installation
Download the latest `.deb` package from Releases and install:

```bash
sudo apt install ./cockpit-ufw-manager_1.0.0_all.deb
